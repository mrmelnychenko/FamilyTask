# FamilyTask

## 📌 Поточний стан розробки

### Фаза 1: Налаштування проєкту + Supabase

## ✅ Зроблено

- Створено проєкт на Expo (React Native)
- Налаштовано базову структуру папок (`src`, `app`)
- Підключено Supabase
- Отримано та використано API ключі
- Створено таблицю `profiles` у базі даних
- Увімкнено RLS (Row Level Security)
- Налаштовано базові політики доступу

---

## 🔐 Реалізовано функціонал

- Реєстрація користувача (email + password)
- Створення користувача через Supabase Auth
- Спроба створення профілю в таблиці `profiles`
- Створено екран реєстрації (`RegisterScreen`)
- Налаштований базовий роутинг (Expo Router)
